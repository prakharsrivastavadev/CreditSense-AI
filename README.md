# CreditSense AI

CreditSense AI is an AI-powered credit score analysis and financial health dashboard built with Python and Streamlit. It helps users understand their credit profile, estimate loan eligibility, assess financial risk, and visualize credit-related insights through interactive dashboards.

## Features

- 📊 Credit score analysis
- 💳 Financial health dashboard
- 🏦 Loan eligibility estimation
- 📈 Credit utilization tracking
- 📉 Debt-to-income ratio analysis
- 🚨 Credit risk assessment
- 📂 CSV import and export
- 🔍 Search and filter customer records
- 📋 Interactive analytics and reports
- ⚡ Responsive Streamlit interface

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/CreditSense-AI.git
```

Navigate to the project directory:

```bash
cd CreditSense-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
