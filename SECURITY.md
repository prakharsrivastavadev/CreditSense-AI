# Security Policy

## Supported Versions

The following versions currently receive security updates.

| Version | Supported |
|----------|-----------|
| 1.x | ✅ Yes |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** create a public GitHub Issue.

Instead, include the following information in your report:

- Description of the vulnerability
- Steps to reproduce
- Expected behavior
- Actual behavior
- Potential impact
- Screenshots or logs (if available)

All reports will be reviewed and addressed as quickly as possible.

---

## Security Best Practices

- Keep project dependencies updated.
- Never commit API keys, passwords, or secrets.
- Store sensitive credentials using environment variables.
- Install packages only from trusted sources.
- Regularly review third-party dependencies for vulnerabilities.
- Validate customer and financial data before processing.

---

## Out of Scope

The following are generally **not** considered security vulnerabilities:

- Documentation improvements
- UI or design suggestions
- Feature requests
- Performance optimizations
- Typographical errors

---

## Responsible Disclosure

Please allow adequate time for investigation and remediation before publicly disclosing any security issue.

Thank you for helping improve the security of CreditSense AI.
