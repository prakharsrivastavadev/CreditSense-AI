# Contributing to CreditSense AI

Thank you for your interest in contributing to CreditSense AI.

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/your-username/CreditSense-AI.git
```

3. Navigate to the project directory.

```bash
cd CreditSense-AI
```

4. Install the required dependencies.

```bash
pip install -r requirements.txt
```

5. Run the application.

```bash
streamlit run app.py
```

---

## Development Guidelines

- Follow PEP 8 coding standards.
- Write clean, modular, and well-documented code.
- Keep commits focused on a single feature or bug fix.
- Test all changes before submitting.
- Update documentation when introducing new functionality.

---

## Pull Requests

Before submitting a pull request:

- Ensure the project runs successfully.
- Verify existing functionality is not affected.
- Include meaningful commit messages.
- Link related issues where applicable.
- Update documentation if required.

---

## Reporting Bugs

Please include:

- Operating System
- Python Version
- Streamlit Version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or logs (if applicable)

---

## Feature Requests

When suggesting a feature, please describe:

- The problem being solved
- Your proposed solution
- Expected benefits
- Alternative approaches considered

---

## Questions

If you have questions or need assistance, please open a GitHub Issue.
